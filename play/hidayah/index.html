A 2D educational RPG made in Java. Explore the world, talk to the characters and answer quiz questions.

Loading takes a few seconds the first time. A keyboard is needed to play.

Click the game first, then move with W A S D. Walk up to a teacher or a chair and press Enter to talk or start a quiz. Enter also picks an answer.

Built from the original Java code and running in the browser with CheerpJ. The online leaderboard is turned off in this version. View the code on GitHub.
